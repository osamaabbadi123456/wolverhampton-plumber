# Wolverhampton Plumber Content Pack

This pack contains ready files and marketing assets.

## Code files
- `app/siteLinks.ts` — central nav/footer links including new advice articles.
- `app/SiteHeader.tsx` — desktop dropdown + mobile menu. Dropdown closes when a link is clicked.
- `app/layout.tsx` — imports shared links, logo `/brand/logo.svg`, footer with all service/area/advice links.
- `app/icon.svg` — custom favicon/app icon to replace the default Next style.
- `app/robots.ts` — clean robots file.
- `public/llms.txt` — AI-friendly site summary.
- `public/ai-summary.json` — structured AI-friendly summary.
- `app/globals.nav-footer.additions.css` — append to `app/globals.css` if these classes are not already present.

## Pinterest / Canva-style assets
- `public/pins/*.png` — 5 vertical pin images, 1000x1500.
- `marketing/pins/pinterest-upload-metadata.csv` — title, description, destination URL, alt text.
- `marketing/pins/canva-pin-design-guide.md` — brand layout guide.

## Business profile assets
- `marketing/business/citation-profile-copy.md`
- `marketing/business/citation-profile-fields.csv`
- `marketing/business/profile-post-ideas.md`

## Video assets
- `marketing/videos/*.mp4` — 5 silent vertical draft videos generated from the pin artwork.
- `marketing/videos/short-video-scripts.md` — captions/voiceover scripts.

## Note
This pack does not create external accounts or publish to Pinterest/Canva/social platforms. Those require login/API access. The upload-ready assets and text are included.

Sitemap is intentionally not included because it was requested after pins.
